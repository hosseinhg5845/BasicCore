### BasicCommands
| Command | Description |
|---------|-------------|
| `/msg <player> <message>` | Send a private message to another player |
| `/buy` | Display the store link |
| `/store` | Display the store link |
| `/ping` | Get your ping |
| `/twitter` | Display the twitter link |
| `/website` | Display the website link |
| `/youtube` | Display the youtube link |
| `/reply` | Shortcut to reply to a message |
| `/r` | Shorter shortcut to reply to a message |
| `/settings` | Opens the settings menu |
| `changelog` | Opens the changelog menu |
| `tiktok` | Display the tiktok link |
| `/join <server>` | Joins a server |
